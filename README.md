# PH1 第3回チェックテスト｜Bean Route

カフェ紹介サイト「Bean Route」を作ります。制限時間45分・**AI利用可**。
時間内に全部は終わらない量です。できたところまでで提出してください。

## テストの進め方

以下のFigmaを開き、デザインと仕様書に沿って `index.html` と `script.js` を完成させてください
https://www.figma.com/design/z5b14O1VMKaVijJokzyUMq/?node-id=2-2

左がデザイン（PC）、右が仕様書です。指定はすべて仕様書に書いてあります。

### ⚠ 必ず VSCode の Live Server で開くこと

`index.html` をダブルクリックして開くと `data.json` を読み込めません。
VSCode 右下の「Go Live」から開いてください。

### ⚠ そのほかの注意

- 写真は `images/` のものを使うこと
- カフェの情報は `data.json` から取得すること（JavaScriptに直接書くのは不可）
- `data.json` は編集しないこと
- スマホ版のデザインは配布しません。幅を狭めたときに崩れなければOKです

## ファイル

| ファイル | 説明 |
|---|---|
| `index.html` | 骨組み。ヘッダー・メインビジュアル・カードは自分で作る |
| `script.js` | 空。JavaScriptはすべてここに書く（読み込みは設定済み） |
| `data.json` | カフェ9件のデータ |
| `images/` | `hero.jpg` とカフェ写真9枚 |

## 提出物

`index.html` / `script.js` / `data.json` / `images/` 一式（提出方法は別途案内します）
